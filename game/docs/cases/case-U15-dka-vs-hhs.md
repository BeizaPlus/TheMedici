## HONK is not a third disease

**HONK** (hyperosmolar non-ketotic coma) = historical UK term for **HHS** (hyperosmolar hyperglycemic state). Same entity.

## Fork table (ADA 2024 / Endotext)

| | DKA | HHS |
|---|-----|-----|
| Onset | Hours–2 days | Days–weeks |
| Glucose | ≥200 (often 250–600) | Often >600 |
| Ketones | β-OHB ≥3 or urine ≥2+ | Minimal |
| pH / HCO3 | <7.3 / <18 | ≥7.3 / ≥15 |
| Osmolality | Moderate ↑ | >320 mOsm/kg |
| Exam | Kussmaul, abdominal pain, fruity breath | AMS, extreme dehydration, little GI pain |
| Treatment emphasis | Insulin + fluids + K | **Fluids first**, cautious insulin, slow correction |

~1/3 of crises are mixed DKA-HHS.
