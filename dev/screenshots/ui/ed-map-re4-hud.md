## RE4 → ED mapping

| RE4 | DotPhrase ED |
|-----|----------------|
| Objective (“Return to helicopter”) | `Move patient to {step node}` |
| VIP Suite / Helipad labels | Triage, Resus, Lab, Meds, **ICU · Ward · Obs · Transfer** |
| Gold player chevron | Patient token on floor plan |
| Left diamond rail | Path stops on algorithm |
| BATTERY / MEMORY bars | TRIAGE / LABS / MEDS / DISPO progress |
| AREA MAP footer | “Emergency Department” + current room |
